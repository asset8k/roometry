# Catalogue expansion: 106 → 214 models

The expansion adds 108 models across four batches, including the follow-up low and medium open shelving variants. The complete catalogue now covers 73 semantic object types; variants share types when their purpose is the same. Existing asset IDs remain valid.

Follow-up variants: `shelf_low_metal_01` (1.05 × 0.8 × 0.35 m, two tiers) and `shelf_medium_metal_01` (0.65 × 1.1 × 0.32 m, three tiers). Both provide actual shelf support areas and are searchable through the same MCP catalogue.

New types: `countertop`, `faucet`, `shower_fixture`, `wall_panel`, `ceiling_detail`.

All additions use shared browser/CPU-render components, conservative collision parts, nominal dimensions, mounting metadata and declared support areas. Dimensions remain catalogue examples, not photo measurements.

Installed fixtures remain protected under the existing redesign contract. The MCP catalogue exposes every model; construction and chat receive relevant variant shortlists that preserve mounting alternatives and current selections.

This step expands representation. Fixture-to-fixture assembly, placement quality, global lighting and material realism remain the following milestones.

Verification: 2,649 backend tests and 660 frontend tests passed (two opt-in live-artifact frontend tests skipped); production build passed. All 110 added mounting configurations passed shared geometry/support checks and actual browser-mesh tests. Thirty-two representative models were also inspected in an isolated browser preview, which was removed afterward. No paid model calls were made. Default chat addition metadata remains bounded at 20,341 JSON characters, with all editable semantic types retained.
